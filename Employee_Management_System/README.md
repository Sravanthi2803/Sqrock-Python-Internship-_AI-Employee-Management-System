\# AI-Based Interview \& Employee Management System



\## Project Description



This project is a Python-based Employee and Interview Management System developed as part of the Week 4 Internship Task.



The system helps manage employee records, candidate interviews, attendance tracking, candidate ranking, and report generation using CSV file storage.



\## Features



\### Employee Management



\* Add Employee

\* View Employee

\* Search Employee

\* Delete Employee



\### Candidate Interview System



\* Register Candidate

\* Resume Skill Matching

\* Interview Status



\### AI Features



\* Resume Skill Matching

\* Interview Question Generator

\* Candidate Ranking System



\### Attendance Management



\* Mark Attendance

\* View Attendance History



\### Reports



\* Employee Reports

\* Candidate Reports



\## Technologies Used



\* Python

\* CSV File Handling

\* Exception Handling

\* Command Line Interface (CLI)



\## How to Run



1\. Install Python 3.x

2\. Open the project folder in VS Code

3\. Open Terminal

4\. Run:



python main.py
